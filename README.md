# MD Atlas

**Ingress Mission Day 活动历史与任务数据档案**

## 项目简介

MD Atlas 记录世界各地的 Ingress Mission Day 活动，整理活动日期、举办地点和任务数据，让散落在不同年份、不同城市的活动记录更容易查找和回顾。

无论是寻找曾经参加过的活动、探索其他城市的任务，还是了解 Mission Day 历年的分布与变化，都可以从这里开始。

**浏览档案：[reiinoki.dpdns.org/md-atlas](https://reiinoki.dpdns.org/md-atlas/)**

## 可以查看什么

- **活动历史**：活动名称、日期、举办城市、国家或地区。
- **任务档案**：任务名称、发布者及阵营、评分、完成次数、路线距离和用时信息。
- **活动状态**：档案中记录的在线、部分离线、离线或已公布状态。
- **来源入口**：通过活动和任务链接查看相应来源页面。

部分活动或任务的信息尚不完整，页面会保留缺失状态，不以推测补全历史记录。

## 浏览方式

- **地图**：从地理位置探索各地的 Mission Day 活动。
- **档案**：搜索城市、国家或地区及任务标题，按年份、地区和状态筛选，查看活动与任务详情。
- **日历**：按年月浏览活动日期，回顾不同时间的活动安排。
- **数据**：查看年份、地域和发布者分布，以及完成次数排行、活动与单任务的最高和最低评分 Top 10。

界面支持中文和英文，并适配桌面与移动设备。

## 数据来源与说明

活动和任务数据主要来自 [Bannergress](https://bannergress.com/) 与 [Ingress Intel Map](https://intel.ingress.com/)。

- **档案不是实时数据**：页面展示采集时的数据快照，任务状态、评分与完成次数可能已经发生变化。
- **历史记录可能存在缺失**：未收录的活动不代表未曾举办，缺少某项任务数据也不代表该任务不存在。
- **距离与用时仅供参考**：它们不等于实际步行路线长度或每位玩家的完成时间。
- **评分榜单**：按当前筛选范围计算。活动评分取其纳入统计的任务评分的算术平均值；单任务按自身评分排序。目前榜单仅纳入大于 0 的评分，空值和 0 值不参与排名。同分时优先排列完成次数更多的条目。
- **榜单并非推荐结论**：未设置最低完成次数门槛；完成次数也不等于评价人数。评分应结合数据规模与任务实际情况理解。

原始活动和任务名称尽量保留来源文本，中文地名用于辅助浏览和搜索。

## 补充与纠错

如果发现遗漏活动、错误日期、地点或任务信息，欢迎通过 [GitHub Issues](https://github.com/ReiiNoki/md-atlas/issues) 提交补充与纠错。

请尽量提供：

- 活动或任务名称，以及本站对应条目。
- 需要补充或修正的内容。
- 可核对的来源链接，例如活动公告、Bannergress 页面或 Intel 任务链接。
