# MD Atlas

[简体中文](README.md) · [English](README_EN.md) · **日本語**

**Ingress Mission Day の歴史とミッションデータをまとめたアーカイブ**

## MD Atlas について

MD Atlas は、世界各地で開催された Ingress Mission Day を記録するプロジェクトです。イベントの日付、開催地、ミッションデータをまとめ、さまざまな年代や都市に散在する記録を検索・閲覧しやすくしています。

参加したイベントを振り返りたいとき、別の都市のミッションを探したいとき、あるいは Mission Day がどのように広がり変化してきたかを知りたいときに、その出発点として利用できます。

**アーカイブを見る：[reiinoki.dpdns.org/md-atlas](https://reiinoki.dpdns.org/md-atlas/)**

## 掲載内容

- **イベント履歴：** イベント名、開催日、開催都市、国または地域。
- **ミッションアーカイブ：** ミッション名、公開者と陣営、評価、完了回数、ルート距離、所要時間の目安。
- **イベントの状態：** アーカイブに記録されたオンライン、一部オフライン、オフライン、または開催予定の状態。
- **参照元へのリンク：** 利用可能な場合、イベントやミッションに対応する参照元ページへのリンク。

一部のイベントやミッションには未収録の情報があります。確認できない情報を推測で補完せず、欠落した状態のまま表示しています。

## 閲覧方法

- **マップ：** 地理的な位置から世界各地の Mission Day を探せます。
- **アーカイブ：** 都市、国または地域、ミッション名を検索し、年、地域、国・地域、状態で絞り込んで、イベントとミッションの詳細を確認できます。
- **カレンダー：** 年月ごとにイベントを閲覧し、Mission Day の開催履歴を振り返ることができます。
- **データ：** 年、地域、公開者ごとの分布、完了回数ランキング、イベントおよび個別ミッションの評価上位・下位 Top 10 を確認できます。

インターフェースは中国語、英語、日本語に対応しており、デスクトップとモバイルの両方で利用できます。

## データの出典と注意事項

イベントおよびミッションのデータは、主に [Bannergress](https://bannergress.com/) と [Ingress Intel Map](https://intel.ingress.com/) から取得しています。

- **リアルタイムデータではありません：** サイトには特定の時点で取得したスナップショットを掲載しています。ミッションの公開状態、評価、完了回数は取得後に変化している可能性があります。
- **過去の記録は完全ではない場合があります：** アーカイブにないイベントが開催されていなかったとは限りません。また、項目が欠けていても、そのミッション自体が存在しないとは限りません。
- **距離と所要時間は目安です：** 実際の徒歩ルートや、すべてのエージェントがミッションを完了するまでの時間を示すものではありません。
- **評価ランキング：** 現在の絞り込み範囲内で計算されます。イベントの評価は、集計対象となる評価済みミッションの算術平均です。個別ミッションは、それぞれの評価に基づいて並べられます。0 より大きい評価のみを対象とし、未取得値と 0 は除外します。同点の場合は、記録された完了回数が多い項目を上位にします。
- **ランキングは推奨順位ではありません：** 最低完了回数の条件は設けておらず、完了回数は評価者数とも異なります。評価は、データ量や各ミッションの状況とあわせてご覧ください。

イベント名とミッション名は、可能な限り参照元の表記を維持しています。中国語の地名は、閲覧と検索を補助するために追加しています。

## 情報の追加・訂正

未収録のイベントや、日付、場所、ミッション情報の誤りを見つけた場合は、[GitHub Issues](https://github.com/ReiiNoki/md-atlas/issues) からお知らせください。

可能であれば、次の情報を添えてください。

- イベント名またはミッション名と、該当する MD Atlas の項目。
- 追加または訂正が必要な内容。
- イベント告知、Bannergress ページ、Intel のミッションリンクなど、確認可能な参照元。

## 関連プロジェクトとリソース

- **[Ingress](https://ingress.com/)：** ゲームの公式サイトおよびイベント告知の掲載元。
- **[Bannergress](https://bannergress.com/)：** ミッションバナーとルートを閲覧できるコミュニティリソースであり、本アーカイブの主要なデータソースの一つです。
- **[Ingress Intel Map](https://intel.ingress.com/)：** 公式マップおよびミッション情報への入口。
- **[IITC-CE](https://iitc.app/)：** コミュニティによってメンテナンスされている Intel Map 拡張ツールで、ミッションデータの収集補助に使用しています。
- **[Fev Games](https://fevgames.net/)：** Ingress のコミュニティガイド、イベント記事、歴史資料。
- **[OpenFreeMap](https://openfreemap.org/) / [OpenStreetMap](https://www.openstreetmap.org/)：** MD Atlas で使用している地図サービスと地図データ。
